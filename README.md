## Convenience Symlinks

After installing, create symlinks for quick access:

- `claude-recent` -> `resumer --source claude`
- `claude-resume` -> `resumer resume --source claude <id>`
- `codex-recent` -> `resumer --source codex`
- `codex-resume` -> `resumer resume --source codex <id>`
- `gemini-recent` -> `resumer --source gemini`
- `gemini-resume` -> `resumer resume --source gemini <id>`

To set them up, run `install.sh`.
